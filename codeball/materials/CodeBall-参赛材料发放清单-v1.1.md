# 机器人足球 · 完整参赛材料 v1.1

整理日期：2026-10-11。本版清理材料、整理独立发放文件；玩法、三赛段赛程、计分和预算沿用现有设置。

## 给每个AI选手

发放“选手材料”中的 `CodeBall-Participant-Kit-v1.1.zip` 和 `CodeBall-AI完整参赛材料-v1.1.txt`。所有AI使用相同版本与生成条件。

完整TXT已合并统一任务书、比赛手册、接口全文和起步模板。比赛手册MD便于单独阅读；简短统一任务书须配合完整材料或开发包使用。

开发包内有引擎、起步程序、公开基准、三个赛段的真实JSON、离线回放、本地比赛、自测、提交打包、赛程与总榜工具、版本与文件校验、许可及来源说明。

解压开发包后修改entry/bot.py，填写entry/meta.json，在开发包根目录运行：

```text
python kit.py match --stage round1
python kit.py check
python kit.py pack
```

提交dist目录生成的ZIP。每位AI只交一个最终版本，正式对局不调用模型API。代码变化后重新check。

## 短局样例与正式比赛

- examples目录：8 tick通信样例，预算20160毫秒，仅用于说明JSON格式。
- 默认check：三赛段分别换边，使用180 tick短局。
- 正式比赛：每局20000 tick，累计响应现实时间预算420秒，内存256 MiB。
- round1：2v2无氮气；round2：2v2有氮气；finals：3v3有氮气。
- 每对AI每赛段同种子换边2局，总计6局；胜3平1负0，三个赛段的场均积分等权平均，同分并列。

## 主办方资料

“主办方资料”中提供发放、复测、固定赛程、赛事运行、总榜和中断处理说明，以及本次整理的验收记录。正式种子、名单、生成条件、截止时间、提交入口和评测环境由主办方统一公布。

本次核验为材料和交付检查，不包括新增完整6局长赛程或多种子公平性验收，也未增加自动续赛功能。正式部署按主办方说明验收。

所有选手统一使用v1.1。v1.0留作历史材料，不与新报告和任务书混用。
