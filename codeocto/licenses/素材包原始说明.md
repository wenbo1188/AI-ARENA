# 八方旅人 II · 回放素材包 v1

这是第一批可接入素材：八人基础关键姿态、六类武器与六属性特效、治疗/复活/破防/潜力特效、合成音效及技能组合配置。角色为本次重新设计的版本，不是原游戏资源提取。

## 打开方式

解压后直接用浏览器打开 `preview.html`。不需要安装依赖或启动服务器。可以切换角色、动作、特效、速度、朝向，点击任一姿态停在单帧查看；点击“试听音效”播放对应声音。

## 内容

| 项目 | 数量 | 路径 |
| --- | ---: | --- |
| 角色基础透明图 | 8 | `characters/*.png` |
| 独立关键姿态 | 64 | `characters/<角色>/<姿态>.png` |
| 角色图集 | 8 | `characters/<角色>/atlas.png` |
| 特效纹理 | 16 | `effects/<特效>/texture.png` |

八个姿态依次为：待机、蓄力、攻击、收招、施法、受击、破防、倒下。舞娘的脸与视线已朝向右侧；镜像用于右侧队伍时会朝向场内。

## 动画性质与范围

- 这是**关键姿态版本**。攻击使用蓄力、命中、收招三张不同姿态衔接，尚未绘制每个动作的完整中间帧，不等同于每动作 8–12 帧的完整逐帧包。
- 特效的 12 帧由绘制的效果纹理经过缩放、转动、位移、透明度和闪烁生成，属于纹理驱动动画。
- 六种物理武器特效与六属性魔法均可独立叠加。角色图内持有的是其示范武器：光为剑、爱格妮娅为匕首、帕特提欧为枪、奥兹巴尔多和提米诺斯为杖、斯洛妮为双匕首、欧修缇为弓、卡斯蒂为斧。本批未画同一角色所有换武器动作。
- 技能组合预设是演出建议。目标、命中数、伤害和增幅应以回放数据为准。比如帕特提欧的幸运之箭可使用弓特效，但其图内武器仍是示范用枪；正式接入此技能前应换用对应武器的角色动作。
- 头像和特写为当前回放中已有的素材，方便配套使用；本批没有把它们重做为新的动态立绘。
- 尚未包含：全员胜利/独立防御姿态、全技能专属连续动画、召唤物，以及完整的暴击/弱点/异常状态图标包。

## 尺寸、锚点、朝向

角色帧为 **384×288 RGBA PNG**，图集为 4 列×2 行，尺寸 **1536×576**。统一锚点为 `[192, 264]`，表示脚底落点。透明外边距用于容纳长枪、刀和倒地姿态。所有帧默认朝右，镜像时围绕该锚点翻转。帕特提欧等长武器角色不会因为武器延伸而整体缩得特别小。

特效帧为 **256×256 RGBA PNG**，图集为 4 列×3 行，尺寸 **1024×768**，锚点为 `[128,128]`。`source-over` 为默认混合方式；可选再以较低透明度叠加 `lighter` 作辉光。

音效为 22050 Hz、单声道、16-bit PCM WAV，属于原创程序合成，不含原作声音或音乐。

## 接入

加载 `asset-manifest.js` 和 `asset-player.js` 后：

```js
const player = await TravelerAssets.load(ASSET_MANIFEST);
player.drawCharacter(ctx, 'hikari', 'attack', elapsedMs, footX, footY, {
  scale: 0.30,
  flip: false,
});
player.drawEffect(ctx, 'sword', elapsedMs - 160, targetX, targetY, 0.65);
```

`manifest.json` 的帧矩形、锚点、帧时长、循环标记和 `hitAt` 可直接供其他引擎读取。普通攻击触发攻击片段，命中时让目标触发 `hurt`，破防使用 `break`，倒下使用 `ko`，复活使用 `revive`。最终回放数值仍应由原事件推进。

技能配置：短刀之舞、突然袭击、幸运之箭、狙击、会心之枪、冰冻魔法、雷击魔法、属性混乱、治疗术、复活魔法、天裂斩。
