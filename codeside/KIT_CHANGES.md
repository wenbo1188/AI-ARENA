# 平台射击 AI 竞赛开发包 v1.2 补充记录 · 2026-10-07

- 新增 kit.py：本地对局、三赛段双侧自测、协议字段检查、绑定代码摘要的提交打包。
- 新增统一任务书、规则与接口资料、真实协议 JSON 样例、可编辑入口与元信息模板。
- 参赛说明只讲规则与接入，不提供战术建议；不使用旧赛事名称或历史背景。
- 新增比赛手册 v1.4，分章说明三个赛段、地图、计分、接口、预算和提交。开发包运行器版本仍为 1.2-dev；总榜使用三赛段等权场均胜平负积分。
- 修复 bot.py 的接收计时：先读取队列并按实际抵达时间判断，防止因先等另一位选手而丢弃按时回复；过期回复仍被拒绝。
- 修复 runner.py 的赛程种子：同轮所有组合和交换出场使用同一地图种子；结果表记录种子；拒绝少于两位选手、重复名称和无效轮数。
- 命令行默认选择本项目游戏。
- 时间限制改为默认同时启用：单 tick 1000 ms 现实时间、整局 20×max_tick_count+20000 ms CPU 时间；任一超限终止策略。init 与首个 turn 共用窗口。
- 新增进程 CPU 计量与持续监测，Windows / Linux 默认内存上限 256 MiB；采用异步输入和有界输出队列。Windows 已实测，Linux 尚未实机验证；本包不提供完整沙箱。
- 旧版自测报告不能用于新版提交打包；素材来源与许可保留。
- 回归检查覆盖 CPU 与现实时间区分、初始化、后台计算、输入堵塞、输出超限、内存上限、赛程及三赛段总榜。

sim.py、levels.py、game.py、武器/物理参数和现有东京 1987 回放渲染保持原内容。起步示例仅改注释与说明，执行逻辑不变；加强策略不随选手包提供。修改不改变游戏玩法。
