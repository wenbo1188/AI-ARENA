# 主办方操作说明

结论：可以立即开展 AI 模型写机器人的开发/内测。游戏功能已齐，不能把当前环境直接宣称为面向任意提交的正式隔离评测平台。待定事项见检查报告。

## 发给每个 AI 模型

所有模型使用同一份 AI-Platform-Participant-Kit-v1.2.zip。具备文件与执行工具时，附整包，发送 docs/03-AI统一任务书.txt；只支持文本附件时，附 docs/04-AI单文件材料.txt（已经包含任务书、规则、接口和起步模板）。不要重复粘贴两份相同规则。

完整比赛说明见 docs/05-比赛规则与参赛手册.md（手册 v1.3）；可作为独立 Markdown 附件发给所有选手。手册与单文本材料中的三赛段定义一致。

开始前统一生成预算、工具权限和重试/反馈次数，并将它们补充到所有模型相同的任务提示。模型不能各用不同的提示词或有的看到额外强策略。不能把 ZIP 模式与纯文本模式的结果不加说明地直接混排，因为两者可用工具和本地运行条件不同。

模型只返回代码时，将完整 Python 代码保存为单个 bot.py。去除外层代码围栏可以统一自动执行，但不要只给某个模型人工修 bug。任何人工修改、额外提示、失败重试都记入模型参赛记录.csv。表中的八行仅是空白模板，不代表指定八位选手。

## 收件和复测

每名选手独立目录，如 incoming/AI-01/bot.py 和 meta.json。保存原始回答和原文件摘要；不要把一个选手的文件覆盖成另一个选手。不要用旧 submit 命令反复覆盖同名历史提交。

在准备好的隔离评测环境里，对每份代码重新执行：

```sh
python kit.py check --bot incoming/AI-01/bot.py --ticks 3600
```

默认即启用单 tick 1000 ms 现实时间与整局 CPU 累计预算，内存 256 MiB；无需附加时间模式参数。将每次 results/check.json 另存到该选手档案，避免下一次自测覆盖。自带报告只供参考，不能直接信任 passed 字段。正式评测还应添加新的隐藏种子和完整时长对局，检查输出洪泛、不读输入、死循环和非法行为的外部终止能力。

## 试跑循环赛

下列命令用于已审阅的本地基准，验证调度、排行榜和回放流程，不是正式赛程：

```sh
python -m arena tournament --game codeside A=bots/codeside/quickstart_bot.py B=bots/codeside/quickstart_bot.py --rounds 1 --seed 101 --parallel 1 -o stage=round1 --out results/demo
```

全部 AI 参加 round1、round2、finals 三个赛段，不淘汰；每个赛段采用相同地图轮数 R，同轮同图换边。每场胜 3、平 1、负 0，赛段得分为场均积分，总分为三个赛段得分等权平均，同分并列。

分别将赛段结果保存为 results/event/round1、round2、finals，完成全部赛程后，在开发包根目录执行 `python standings.py results/event --rounds R`（把 R 替换为赛前公布的正整数）。生成 overall/overall.json 和 overall/overall.html。旧的单赛段榜单中游戏分差等排序不作为最终排名依据。

N 位选手、R 轮、一个赛段共 N×(N−1)×R 场。建议先按统一机器、parallel=1 测量耗时，再制定比赛日程；不要把游戏内 60 秒当作机器的实际运行时长。

## 正式开赛前还需落地

填写 event-config.DRAFT.json（它是登记表，不是可直接传给引擎的配置），公开模型生成约束、轮数、种子、运行预算、收件方式和截止时间；冻结包与提交摘要。

现有 BotProcess 使用本机 Python 子进程，清理环境变量不等于隔离。需要由主办方提供每个 bot 独立的受限执行环境、禁网、禁止访问其他 bot 和裁判文件、资源与输出上限、整场看门狗。仅把整个竞技场和所有选手放在同一个容器里不能实现选手相互隔离。本包不宣称已完成该部署。

当前 runner 使用异步 stdin 写入，stdout 单行及队列有界；Windows 使用 Job Object 限制内存并阻止新建子进程，Linux 使用地址空间限制并清理进程组。进程启动与限制设置之间不是原子隔离边界，Linux 也不是完整子进程隔离；正式环境仍需独立隔离与整场看门狗。CPU 通过进程用户态加内核态时间计量，约 5 ms 检查并在接收回复时复查。Windows 已实测，Linux 未实机验证；两平台内存计量口径不同。

保留原素材来源说明与相应文件；正式公开发布前完成上游素材清单核对。本次不作“与 2019 官方引擎完全等价”的宣称。
