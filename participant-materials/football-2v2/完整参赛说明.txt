## 六人积分赛和名次赛

每项先进行五轮单循环，每轮三大场；每人每轮出场一次，与其余五名选手各交手一大场，共十五大场、三十小局。

每大场同种子换边两局。小局胜 3、平 1、负 0；两局积分合计高者赢大场，相同则大场平局。积分榜按大场胜 3、平 1、负 0 排序。

前四进入半决赛：第一对第四、第二对第三。胜者进入决赛决定冠亚军，负者进入季军赛决定三、四名。积分第五与第六进行五六名排位赛。最终前四按淘汰赛结果排列，第五、第六按排位赛结果排列。

每项基础赛程二十大场；同分附加赛不计入这二十大场。七项分别排名，无跨项目合成冠军。

## BO5

半决赛、决赛、季军赛、五六名排位赛及两人同分附加赛，均先取得三局胜利者获胜，随后停止。平局不计胜场，实际对局数可能超过五局，不用小局累计积分代替 BO5 胜场。

局位按非平局结果推进。第一、二局位同种子换边；第三、四局位使用另一个种子换边；第五局位使用新种子，现场随机抽签决定首方出场侧。同阶段使用相同种子序列和第五局位抽签安排。平局补赛保留该局位的出场侧，更换新种子；补赛分出胜负后进入下一局位。

连续平局没有自动判胜、抽签决胜或固定小局上限；必要时可暂停执行并续跑，不得将暂停当成比赛结束。

## 同分

积分赛同分选手首先比较相互对战的大场积分，多人同分按整个同分组计算一次小积分榜；仍相同的再比较下列全部积分赛指标，不重新递归计算缩小组的相互积分。

- 足球：小局净胜球，再比小局总进球。
- 平台射击、旅人：小局净胜场数（胜场减负场）。

仍同分时进行附加赛：两人 BO5；三人以上进行同种子换边两局的附加单循环，大场胜 3、平 1、负 0。附加赛同分时，足球依次比较该次附加赛净胜球、总进球，其他项目比较该次附加赛小局净胜场。仍无法区分的剩余选手继续附加赛，两人用 BO5，多人再打单循环。附加赛仅决定原同分组内顺序，不影响其他选手。

## 种子

练习种子 12、21、34 公开。正式种子不提前生成；冻结代码后，在对应轮次或对局即将运行时由系统随机生成并立即记录，不人工挑选或重抽，避开公开练习种子。

同一独立比赛的积分赛每轮生成一个种子，该轮三场共用，每场两局换边共用。不同轮重新生成。淘汰、排位和附加赛使用新种子，同阶段使用相同序列；多人附加单循环共用该次附加赛种子。赛后公开种子及逐局记录。

## 运行预算及故障

| 项目 | 单 tick 现实时间上限 | 每策略整局预算 | 内存 |
|---|---|---|---|
| 足球 | 20 秒 | 累计响应现实时间 `20 × max_tick_count + 20000` 毫秒；标准局 420 秒 | 256 MiB |
| 平台射击 | 1 秒 | 进程用户态与内核态 CPU 时间 `20 × max_tick_count + 20000` 毫秒；标准局 92 秒 | 256 MiB |
| 旅人对决 | 1 秒 | 进程用户态与内核态 CPU 时间 60 秒 | 256 MiB |

init 与首次 turn 共享首次窗口，无额外初始化宽限。整队共享一个进程及预算，资源预算不因错误而重置。足球累计响应时间包含初始化、发送排队和等待回复，不包含裁判物理推进；CPU 预算包含启动、初始化及后台计算，不计睡眠等待。

- 普通 tick 超时或协议格式错误（缺失 tick、字段类型错误等）：仅当前 tick 默认行动，进程保留；后续按时回复合法动作即可恢复。迟到的旧 tick 回复丢弃，不用于新 tick。
- 初始化超时或回复不合法：终止策略，本局默认行动接管，不重启。
- 进程崩溃或退出、整局预算耗尽或内存超限：本局剩余部分默认行动接管，不重启。
- 游戏内容不合法但协议结构合法：依引擎公开规则忽略或回退，不等同协议错误。

足球默认全部己方机器人零动作；射击默认空动作；旅人缺少选人时随机补齐，缺少配置用空配置，战斗默认普通攻击对方第一个存活角色。合法回复中的不可用行动按游戏规则回退。物理、已有子弹、状态效果照常推进。双方均永久失效时，足球、射击沿用引擎的提前结束条件；旅人继续默认行动直到正常结束。故障不直接判负、不触发重赛，按最终战况结算。

stdout 每行 JSON 最多 65536 字符，最多缓存 16 行；输入队列积压、输出洪泛等管道资源超限会永久终止策略，以保护裁判，不属于可恢复的单条协议错误。stderr 只保留有界日志。

# 游戏机制与接口源文档

正式规则由根目录 RULES.md 统一生成；本文件只维护游戏机制、协议与数值。

## 游戏世界

- 世界是三维的，被一个带圆角的箱形场地包围，两端各有一个球门。机器人和球都是球体，不能离开场地。
- **x 轴**水平、平行于中线，**y 轴**竖直向上，**z 轴**水平、从己方球门指向对方球门。
- **坐标会针对你转换**：无论你实际在哪一边，你收到的所有坐标、速度、法向量里己方半场都在 z < 0，对方球门在 z > 0；你的动作也按这个视角给出，竞技场会自动转换回去。
- 开局和每次进球后：机器人随机落在己方半场的地面上，你的机器人和对方机器人关于场地中心 (0, 0) 对称（所以到球的距离相同）。球放在 (0, y, 0)，y 在 `BALL_RADIUS` 到 `4 × BALL_RADIUS` 之间均匀随机，静止。氮气赛中所有机器人的氮气重置为 `START_NITRO_AMOUNT`；无氮气赛中恒为 0。
- 时间是离散的，以 tick 计（每秒 `TICKS_PER_SECOND` = 60 个）。每个 tick 开始时竞技场把世界状态发给双方策略、收到动作，再按动作模拟这一 tick。比赛最多 `max_tick_count` 个 tick（本赛事 20000），双方策略都崩溃时提前结束。

## 场地

场地参数在 `rules.arena` 里，默认：

| 参数 | 值 | 说明 |
|---|---|---|
| width | 60 | x 方向宽度 |
| height | 20 | 高度（天花板） |
| depth | 80 | z 方向长度（不含球门） |
| bottom_radius | 3 | 地面和墙面相接处的圆角 |
| top_radius | 7 | 天花板和墙面相接处的圆角 |
| corner_radius | 13 | 俯视时四个角的圆角 |
| goal_width | 30 | 球门宽 |
| goal_height | 10 | 球门高 |
| goal_depth | 10 | 球门深 |
| goal_top_radius | 3 | 球门内顶部圆角 |
| goal_side_radius | 1 | 门框外沿的圆角 |

精确形状由下面物理代码里的 `Arena.dan`（点到场地的距离和法向量）定义。球和机器人都可以进入球门内部。

## 球和机器人

- 球半径 `BALL_RADIUS`，质量 `BALL_MASS`，撞场地的恢复系数 `BALL_ARENA_E`。
- **球整体越过球门线才算进球：`abs(ball.z) > arena.depth / 2 + ball.radius`。** 进球后 `RESET_TICKS` 个 tick 重新开球（这期间模拟继续，但不再计分）。
- 机器人质量 `ROBOT_MASS`，半径在 `ROBOT_MIN_RADIUS` 到 `ROBOT_MAX_RADIUS` 之间，随起跳速度变化：
  `radius = ROBOT_MIN_RADIUS + (ROBOT_MAX_RADIUS - ROBOT_MIN_RADIUS) * jump_speed / ROBOT_MAX_JUMP_SPEED`。
  跳跃时模拟器认为半径以 `jump_speed` 的速度在增大，所以起跳速度也决定了撞球的力度，略大的半径还能让机器人蹬墙起跳。
- 机器人撞场地的恢复系数是 0（完全非弹性）；机器人撞球、机器人互撞的恢复系数在 `MIN_HIT_E` ~ `MAX_HIT_E` 之间均匀随机。

## 氮气

- 足球 2v2 无氮气赛（`round1`）没有氮气，`nitro_amount` 恒为 0，也没有氮气瓶。足球 2v2 氮气赛（`round2`）与足球 3v3 氮气赛（`finals`）开启氮气。三者是独立比赛，配置标识不表示晋级阶段；同一项比赛不会因进入淘汰赛而改变人数或氮气规则。
- 氮气可以给机器人任意方向的加速度，加速度不超过 `ROBOT_NITRO_ACCELERATION`。机器人最多储存 `MAX_NITRO_AMOUNT` 点氮气，每点氮气能改变 `NITRO_POINT_VELOCITY_CHANGE` 的速度。
- 场上共 4 个氮气瓶，在 `(±NITRO_PACK_X, NITRO_PACK_Y, ±NITRO_PACK_Z)`，半径 `NITRO_PACK_RADIUS`。机器人中心和氮气瓶中心的距离不超过两者半径之和就会拾取，氮气补满到 100（氮气已满的机器人不会拾取）。被拾取后 `NITRO_PACK_RESPAWN_TICKS` 个 tick 在原地重新出现。

## 控制

每个 tick 给每个机器人一个 `Action`：目标速度、起跳速度、是否用氮气。

- 不用氮气时：只有机器人接触场地时，速度才会朝"目标速度在接触面上的投影"变化，加速度不超过 `ROBOT_ACCELERATION`；接触面越陡加速度越小（乘以法向量的 y 分量），所以贴着墙或天花板时加速度为 0。目标速度长度会先被截断到 `ROBOT_MAX_GROUND_SPEED`。
- 用氮气时：速度同样朝目标速度变化，但与是否接触场地无关（可以在空中转向、向上飞），这时目标速度不受 `ROBOT_MAX_GROUND_SPEED` 限制。
- `jump_speed` 在 0（不跳）到 `ROBOT_MAX_JUMP_SPEED` 之间。机器人和场地碰撞时，碰撞点的相对速度等于起跳速度，因此能跳起来；也可以用它控制撞球的力度。


本项配置由开发包 `EVENT.json` 的 `stage` 确定：`round1` 为每队 2 人、无氮气；`round2` 为每队 2 人、有氮气；`finals` 为每队 3 人、有氮气。选手仅需兼容本项配置。

```json
           "NITRO_POINT_VELOCITY_CHANGE": 0.6, "NITRO_PACK_X": 20.0, "NITRO_PACK_Y": 1.0, "NITRO_PACK_Z": 30.0,
           "NITRO_PACK_RADIUS": 0.5, "NITRO_PACK_AMOUNT": 100.0, "NITRO_PACK_RESPAWN_TICKS": 600, "GRAVITY": 30.0}}
```

必须回复 `{"ready": true}`。策略应读取 `init` 中的参数。**正式比赛使用冻结的本项配置**：`max_tick_count=20000`、`MICROTICKS_PER_TICK=100`，每队人数及氮气开关按上述配置固定；`init` 传递冻结参数，不会为了加快比赛而临时改变玩法或预算。若消息参数与正式规则不一致，按统一规则暂停并复核。

本地短程调试可以通过 `python kit.py match --ticks 180` 或 `python kit.py check --ticks 180` 缩短局长，相应的整局响应预算按统一公式调整；这不改变正式比赛参数。未指定 `--ticks` 时使用本项完整局长。短程结果不代表通过完整准入检查。

## 数据结构

- **Rules**：`max_tick_count` 比赛最大 tick 数，`arena` 场地参数（Arena），`team_size` 每队机器人数，`seed` 随机种子，以及第 3 章用到的全部常数。
- **Game**：`current_tick` 当前 tick，`players` 玩家列表，`robots` 场上**全部**机器人（双方都有），`nitro_packs` 氮气瓶列表（没有氮气时为空），`ball` 球。
- **Player**：`id`、`me`（是否是你）、`strategy_crashed`（策略是否已崩溃）、`score` 当前进球数。
- **Robot**：`id`、`player_id`（属于哪个玩家）、`is_teammate`（是不是你的机器人）、`x`/`y`/`z` 中心坐标、`velocity_x`/`velocity_y`/`velocity_z` 速度、`radius` 当前半径、`nitro_amount` 剩余氮气、`touch` 是否接触场地、`touch_normal_x`/`_y`/`_z` 接触面法向量（指向场内，未接触时为 null）。
- **NitroPack**：`id`、`x`/`y`/`z`、`radius`、`nitro_amount`（拾取后补到多少）、`respawn_ticks`（还有多少 tick 重新出现；**null 表示氮气瓶在场上可以拾取**）。
- **Ball**：`x`/`y`/`z`、`velocity_x`/`velocity_y`/`velocity_z`、`radius`。
- **Action**：`target_velocity_x`/`_y`/`_z` 目标速度，`jump_speed` 起跳速度，`use_nitro` 是否用氮气。

## 物理模拟

模拟基于冲量法，没有摩擦，所有碰撞按顺序依次解决。每个 tick 拆成 `MICROTICKS_PER_TICK` 个微步。下面就是竞技场实际运行的代码（`World._update` 对应伪代码的 `update`，`Arena.dan` 对应 `dan_to_arena`，常数和 3.2 节一致），世界坐标里 1 号玩家的球门在 z < 0。物理关于原点中心对称，你可以直接把它搬进自己的程序做模拟和预测（注意控制计算量）。

每个 tick：竞技场把双方动作写入各机器人的 `a_tvx/a_tvy/a_tvz/a_jump/a_nitro`，然后调用一次 `World.tick()`。

```python
"""3D 足球物理：逐行对照  CodeBall 《Developer Guide》第 3 章的模拟伪代码实现，
常数取自文档 3.2 节和 1.3 节（github.com/MailRuChamps/raic-2018 的 docs/ 目录同源）。

坐标系：x 横向（-width/2 ~ width/2），y 竖直向上（0 ~ height），z 纵向（-depth/2 ~ depth/2）。
1 号玩家（team 0）的球门在 z < 0 一侧，2 号玩家（team 1）的球门在 z > 0 一侧。
"""
from __future__ import annotations

import math
import random

# ---------------------------------------------------------------- 常数
RULES = {
    "ROBOT_MIN_RADIUS": 1.0,
    "ROBOT_MAX_RADIUS": 1.05,
    "ROBOT_MAX_JUMP_SPEED": 15.0,
    "ROBOT_ACCELERATION": 100.0,
    "ROBOT_NITRO_ACCELERATION": 30.0,
    "ROBOT_MAX_GROUND_SPEED": 30.0,
    "ROBOT_ARENA_E": 0.0,
    "ROBOT_RADIUS": 1.0,
    "ROBOT_MASS": 2.0,
    "TICKS_PER_SECOND": 60,
    "MICROTICKS_PER_TICK": 100,
    "RESET_TICKS": 120,              # 2 * TICKS_PER_SECOND
    "BALL_ARENA_E": 0.7,
    "BALL_RADIUS": 2.0,
    "BALL_MASS": 1.0,
    "MIN_HIT_E": 0.4,
    "MAX_HIT_E": 0.5,
    "MAX_ENTITY_SPEED": 100.0,
    "MAX_NITRO_AMOUNT": 100.0,
    "START_NITRO_AMOUNT": 50.0,
    "NITRO_POINT_VELOCITY_CHANGE": 0.6,
    "NITRO_PACK_X": 20.0,
    "NITRO_PACK_Y": 1.0,
    "NITRO_PACK_Z": 30.0,
    "NITRO_PACK_RADIUS": 0.5,
    "NITRO_PACK_AMOUNT": 100.0,
    "NITRO_PACK_RESPAWN_TICKS": 600, # 10 * TICKS_PER_SECOND
    "GRAVITY": 30.0,
}

ARENA = {
    "width": 60.0,
    "height": 20.0,
    "depth": 80.0,
    "bottom_radius": 3.0,
    "top_radius": 7.0,
    "corner_radius": 13.0,
    "goal_top_radius": 3.0,
    "goal_width": 30.0,
    "goal_height": 10.0,
    "goal_depth": 10.0,
    "goal_side_radius": 1.0,
}


# ---------------------------------------------------------------- 到场地的距离（dan = distance and normal）
class Arena:
    def __init__(self, a: dict):
        self.w2 = a["width"] / 2
        self.h = a["height"]
        self.d2 = a["depth"] / 2
        self.br = a["bottom_radius"]
        self.tr = a["top_radius"]
        self.cr = a["corner_radius"]
        self.gtr = a["goal_top_radius"]
        self.gw2 = a["goal_width"] / 2
        self.gh = a["goal_height"]
        self.gd = a["goal_depth"]
        self.gsr = a["goal_side_radius"]
        assert self.br == self.gtr, "规则要求 bottom_radius == goal_top_radius"

    def dan(self, x, y, z):
        """返回 (距离, nx, ny, nz)：点到场地表面的最近距离和指向场内的法向量。"""
        nx_neg = x < 0
        nz_neg = z < 0
        if nx_neg:
            x = -x
        if nz_neg:
            z = -z
        d, nx, ny, nz = self._quarter(x, y, z)
        if nx_neg:
            nx = -nx
        if nz_neg:
            nz = -nz
        return d, nx, ny, nz

    def _quarter(self, x, y, z):
        w2, h, d2, br, tr, cr = self.w2, self.h, self.d2, self.br, self.tr, self.cr
        gtr, gw2, gh, gd, gsr = self.gtr, self.gw2, self.gh, self.gd, self.gsr

        # 用局部变量保存当前最优 (dist, nx, ny, nz)，避免创建对象
        # 地面
        best_d, bx, by, bz = y, 0.0, 1.0, 0.0
        # 天花板
        dd = h - y
        if dd < best_d:
            best_d, bx, by, bz = dd, 0.0, -1.0, 0.0
        # 侧墙 x
        dd = w2 - x
        if dd < best_d:
            best_d, bx, by, bz = dd, -1.0, 0.0, 0.0
        # 球门后墙
        dd = d2 + gd - z
        if dd < best_d:
            best_d, bx, by, bz = dd, 0.0, 0.0, -1.0
        # 底线墙 z（门框以外的部分）
        vx, vy = x - (gw2 - gtr), y - (gh - gtr)
        if x >= gw2 + gsr or y >= gh + gsr or (vx > 0 and vy > 0 and math.hypot(vx, vy) >= gtr + gsr):
            dd = d2 - z
            if dd < best_d:
                best_d, bx, by, bz = dd, 0.0, 0.0, -1.0
        # 球门内的侧壁和顶
        if z >= d2 + gsr:
            dd = gw2 - x
            if dd < best_d:
                best_d, bx, by, bz = dd, -1.0, 0.0, 0.0
            dd = gh - y
            if dd < best_d:
                best_d, bx, by, bz = dd, 0.0, -1.0, 0.0

        def inner(cx, cy, cz, r):
            nonlocal best_d, bx, by, bz
            ex, ey, ez = cx - x, cy - y, cz - z
            ln = math.sqrt(ex * ex + ey * ey + ez * ez)
            dd = r - ln
            if dd < best_d and ln > 1e-12:
                best_d, bx, by, bz = dd, ex / ln, ey / ln, ez / ln

        def outer(cx, cy, cz, r):
            nonlocal best_d, bx, by, bz
            ex, ey, ez = x - cx, y - cy, z - cz
            ln = math.sqrt(ex * ex + ey * ey + ez * ez)
            dd = ln - r
            if dd < best_d and ln > 1e-12:
                best_d, bx, by, bz = dd, ex / ln, ey / ln, ez / ln

        def clamp(v, lo, hi):
            return lo if v < lo else hi if v > hi else v

        # 球门后角
        if z > d2 + gd - br:
            inner(clamp(x, br - gw2, gw2 - br), clamp(y, br, gh - gtr), d2 + gd - br, br)
        # 场地四角（竖直圆柱）
        if x > w2 - cr and z > d2 - cr:
            inner(w2 - cr, y, d2 - cr, cr)
        # 球门口外侧的圆角
        if z < d2 + gsr:
            if x < gw2 + gsr:
                outer(gw2 + gsr, y, d2 + gsr, gsr)
            if y < gh + gsr:
                outer(x, gh + gsr, d2 + gsr, gsr)
            ox, oy = gw2 - gtr, gh - gtr
            vx, vy = x - ox, y - oy
            if vx > 0 and vy > 0:
                ln = math.hypot(vx, vy)
                ox += vx / ln * (gtr + gsr)
                oy += vy / ln * (gtr + gsr)
                outer(ox, oy, d2 + gsr, gsr)
        # 球门内顶部圆角
        if z > d2 + gsr and y > gh - gtr:
            if x > gw2 - gtr:
                inner(gw2 - gtr, gh - gtr, z, gtr)
            if z > d2 + gd - gtr:
                inner(x, gh - gtr, d2 + gd - gtr, gtr)
        # 底部圆角
        if y < br:
            if x > w2 - br:
                inner(w2 - br, br, z, br)
            if z > d2 - br and x >= gw2 + gsr:
                inner(x, br, d2 - br, br)
            if z > d2 + gd - br:
                inner(x, br, d2 + gd - br, br)
            ox, oz = gw2 + gsr, d2 + gsr
            vx, vz = x - ox, z - oz
            if vx < 0 and vz < 0 and math.hypot(vx, vz) < gsr + br:
                ln = math.hypot(vx, vz)
                ox += vx / ln * (gsr + br)
                oz += vz / ln * (gsr + br)
                inner(ox, br, oz, br)
            if z >= d2 + gsr and x > gw2 - br:
                inner(gw2 - br, br, z, br)
            if x > w2 - cr and z > d2 - cr:
                cx, cz = w2 - cr, d2 - cr
                nx, nz = x - cx, z - cz
                ln = math.hypot(nx, nz)
                if ln > cr - br:
                    inner(cx + nx / ln * (cr - br), br, cz + nz / ln * (cr - br), br)
        # 天花板圆角
        if y > h - tr:
            if x > w2 - tr:
                inner(w2 - tr, h - tr, z, tr)
            if z > d2 - tr:
                inner(x, h - tr, d2 - tr, tr)
            if x > w2 - cr and z > d2 - cr:
                cx, cz = w2 - cr, d2 - cr
                nx, nz = x - cx, z - cz
                ln = math.hypot(nx, nz)
                if ln > cr - tr:
                    inner(cx + nx / ln * (cr - tr), h - tr, cz + nz / ln * (cr - tr), tr)
        return best_d, bx, by, bz


# ---------------------------------------------------------------- 实体
class Entity:
    __slots__ = ("x", "y", "z", "vx", "vy", "vz", "radius", "mass", "arena_e", "radius_change_speed",
                 "touch", "tnx", "tny", "tnz", "nitro", "team", "id", "index",
                 "a_tvx", "a_tvy", "a_tvz", "a_jump", "a_nitro", "nitro_used")

    def __init__(self, x, y, z, radius, mass, arena_e):
        self.x, self.y, self.z = x, y, z
        self.vx = self.vy = self.vz = 0.0
        self.radius, self.mass, self.arena_e = radius, mass, arena_e
        self.radius_change_speed = 0.0
        self.touch = False
        self.tnx, self.tny, self.tnz = 0.0, 1.0, 0.0
        self.nitro = 0.0
        self.team = -1      # 0 / 1
        self.id = -1        # 的机器人 id（从 1 开始，全场唯一）
        self.index = -1     # 在本队里的序号
        self.nitro_used = False  # 本 tick 是否真的消耗了氮气（回放用）
        self.a_tvx = self.a_tvy = self.a_tvz = 0.0
        self.a_jump = 0.0
        self.a_nitro = False


class NitroPack:
    __slots__ = ("x", "y", "z", "radius", "alive", "respawn_ticks")

    def __init__(self, x, y, z, r):
        self.x, self.y, self.z, self.radius = x, y, z, r
        self.alive = True
        self.respawn_ticks = 0


# ---------------------------------------------------------------- 世界
class World:
    def __init__(self, rules: dict, arena: dict, team_size: int, nitro: bool, microticks: int, rng: random.Random,
                 disable_random: bool = False):
        self.R = rules
        self.A = arena
        self.arena = Arena(arena)
        self.team_size = team_size
        self.nitro_enabled = nitro
        self.microticks = microticks
        self.rng = rng
        #  local runner 的 --disable-random：碰撞恢复系数固定取 MAX_HIT_E，机器人按 id 顺序处理
        self.disable_random = disable_random
        self.robots: list[Entity] = []
        for team in range(2):
            for i in range(team_size):
                r = Entity(0, rules["ROBOT_RADIUS"], 0, rules["ROBOT_RADIUS"], rules["ROBOT_MASS"], rules["ROBOT_ARENA_E"])
                r.team, r.index, r.id = team, i, team * team_size + i + 1
                self.robots.append(r)
        self.ball = Entity(0, rules["BALL_RADIUS"], 0, rules["BALL_RADIUS"], rules["BALL_MASS"], rules["BALL_ARENA_E"])
        self.packs: list[NitroPack] = []
        if nitro:
            for sx in (-1, 1):
                for sz in (-1, 1):
                    self.packs.append(NitroPack(sx * rules["NITRO_PACK_X"], rules["NITRO_PACK_Y"],
                                                sz * rules["NITRO_PACK_Z"], rules["NITRO_PACK_RADIUS"]))
        self.reset()

    def reset(self):
        """开球：机器人随机落在己方半场地面上，和对方机器人关于场地中心对称（因此到球的距离相同）；
        球在 (0, y, 0)，y 在 BALL_RADIUS ~ 4 * BALL_RADIUS 之间均匀随机。"""
        R, A = self.R, self.A
        for i in range(self.team_size):
            x = self.rng.uniform(-A["width"] / 2 + 4, A["width"] / 2 - 4)
            z = -self.rng.uniform(A["depth"] / 8, A["depth"] / 2 - 6)
            for r in self.robots:
                if r.index != i:
                    continue
                sign = 1 if r.team == 0 else -1
                r.x, r.y, r.z = x * sign, R["ROBOT_RADIUS"], z * sign
                r.vx = r.vy = r.vz = 0.0
                r.radius = R["ROBOT_RADIUS"]
                r.radius_change_speed = 0.0
                r.touch, r.tnx, r.tny, r.tnz = True, 0.0, 1.0, 0.0
                r.nitro = R["START_NITRO_AMOUNT"] if self.nitro_enabled else 0.0  # 无氮气赛恒为 0
        b = self.ball
        b.x, b.z = 0.0, 0.0
        b.y = self.rng.uniform(R["BALL_RADIUS"], 4 * R["BALL_RADIUS"])
        b.vx = b.vy = b.vz = 0.0
        for p in self.packs:
            p.alive, p.respawn_ticks = True, 0

    # ---- 伪代码 ----
    def _move(self, e: Entity, dt: float):
        R = self.R
        sp = math.sqrt(e.vx * e.vx + e.vy * e.vy + e.vz * e.vz)
        if sp > R["MAX_ENTITY_SPEED"]:
            k = R["MAX_ENTITY_SPEED"] / sp
            e.vx, e.vy, e.vz = e.vx * k, e.vy * k, e.vz * k
        e.x += e.vx * dt
        e.y += e.vy * dt
        e.z += e.vz * dt
        e.y -= R["GRAVITY"] * dt * dt / 2
        e.vy -= R["GRAVITY"] * dt

    def _collide_entities(self, a: Entity, b: Entity):
        dx, dy, dz = b.x - a.x, b.y - a.y, b.z - a.z
        dist = math.sqrt(dx * dx + dy * dy + dz * dz)
        pen = a.radius + b.radius - dist
        if pen > 0 and dist > 1e-12:
            ia, ib = 1 / a.mass, 1 / b.mass
            ka, kb = ia / (ia + ib), ib / (ia + ib)
            nx, ny, nz = dx / dist, dy / dist, dz / dist
            a.x -= nx * pen * ka
            a.y -= ny * pen * ka
            a.z -= nz * pen * ka
            b.x += nx * pen * kb
            b.y += ny * pen * kb
            b.z += nz * pen * kb
            dv = ((b.vx - a.vx) * nx + (b.vy - a.vy) * ny + (b.vz - a.vz) * nz
                  - b.radius_change_speed - a.radius_change_speed)
            if dv < 0:
                e = self.R["MAX_HIT_E"] if self.disable_random else self.rng.uniform(self.R["MIN_HIT_E"], self.R["MAX_HIT_E"])
                imp = (1 + e) * dv
                a.vx += nx * imp * ka
                a.vy += ny * imp * ka
                a.vz += nz * imp * ka
                b.vx -= nx * imp * kb
                b.vy -= ny * imp * kb
                b.vz -= nz * imp * kb
            return True
        return False

    def _collide_with_arena(self, e: Entity):
        d, nx, ny, nz = self.arena.dan(e.x, e.y, e.z)
        pen = e.radius - d
        if pen > 0:
            e.x += nx * pen
            e.y += ny * pen
            e.z += nz * pen
            v = e.vx * nx + e.vy * ny + e.vz * nz - e.radius_change_speed
            if v < 0:
                k = (1 + e.arena_e) * v
                e.vx -= k * nx
                e.vy -= k * ny
                e.vz -= k * nz
                return nx, ny, nz
        return None

    def _update(self, dt: float) -> int | None:
        """一个微步。返回进球方（0/1）或 None。"""
        R = self.R
        robots = self.robots[:]
        if not self.disable_random:
            self.rng.shuffle(robots)
        for r in robots:
            if r.touch:
                tvx, tvy, tvz = r.a_tvx, r.a_tvy, r.a_tvz
                ln = math.sqrt(tvx * tvx + tvy * tvy + tvz * tvz)
                if ln > R["ROBOT_MAX_GROUND_SPEED"]:
                    k = R["ROBOT_MAX_GROUND_SPEED"] / ln
                    tvx, tvy, tvz = tvx * k, tvy * k, tvz * k
                dot = r.tnx * tvx + r.tny * tvy + r.tnz * tvz
                tvx -= r.tnx * dot
                tvy -= r.tny * dot
                tvz -= r.tnz * dot
                cx, cy, cz = tvx - r.vx, tvy - r.vy, tvz - r.vz
                cl = math.sqrt(cx * cx + cy * cy + cz * cz)
                if cl > 0:
                    acc = R["ROBOT_ACCELERATION"] * max(0.0, r.tny)
                    step = min(acc * dt, cl)
                    r.vx += cx / cl * step
                    r.vy += cy / cl * step
                    r.vz += cz / cl * step
            if r.a_nitro:
                # target_velocity_change = clamp(target_velocity - velocity, nitro * NITRO_POINT_VELOCITY_CHANGE)
                cx, cy, cz = r.a_tvx - r.vx, r.a_tvy - r.vy, r.a_tvz - r.vz
                cl = math.sqrt(cx * cx + cy * cy + cz * cz)
                lim = r.nitro * R["NITRO_POINT_VELOCITY_CHANGE"]
                if cl > lim:
                    cx, cy, cz = cx / cl * lim, cy / cl * lim, cz / cl * lim
                    cl = lim
                if cl > 0:
                    # velocity_change = clamp(normalize(change) * ROBOT_NITRO_ACCELERATION * dt, length(change))
                    step = min(R["ROBOT_NITRO_ACCELERATION"] * dt, cl)
                    r.vx += cx / cl * step
                    r.vy += cy / cl * step
                    r.vz += cz / cl * step
                    r.nitro -= step / R["NITRO_POINT_VELOCITY_CHANGE"]
                    r.nitro_used = True
            self._move(r, dt)
            js = r.a_jump
            r.radius = R["ROBOT_MIN_RADIUS"] + (R["ROBOT_MAX_RADIUS"] - R["ROBOT_MIN_RADIUS"]) * js / R["ROBOT_MAX_JUMP_SPEED"]
            r.radius_change_speed = js
        self._move(self.ball, dt)
        rs = self.robots
        for i in range(len(rs)):
            for j in range(i):
                self._collide_entities(rs[i], rs[j])
        for r in rs:
            self._collide_entities(r, self.ball)
            n = self._collide_with_arena(r)
            if n is None:
                r.touch = False
            else:
                r.touch = True
                r.tnx, r.tny, r.tnz = n
        self._collide_with_arena(self.ball)
        scored = None
        if abs(self.ball.z) > self.A["depth"] / 2 + self.ball.radius:
            scored = 0 if self.ball.z > 0 else 1
        if self.packs:
            for r in rs:
                if r.nitro >= R["MAX_NITRO_AMOUNT"]:
                    continue
                for p in self.packs:
                    if not p.alive:
                        continue
                    if math.sqrt((r.x - p.x) ** 2 + (r.y - p.y) ** 2 + (r.z - p.z) ** 2) <= r.radius + p.radius:
                        r.nitro = R["MAX_NITRO_AMOUNT"]
                        p.alive = False
                        p.respawn_ticks = R["NITRO_PACK_RESPAWN_TICKS"]
        return scored

    def tick(self) -> int | None:
        """一个 tick（拆成 microticks 个微步）。返回本 tick 的进球方或 None。"""
        dt = 1.0 / self.R["TICKS_PER_SECOND"] / self.microticks
        scored = None
        for r in self.robots:
            r.nitro_used = False
        for _ in range(self.microticks):
            s = self._update(dt)
            if s is not None and scored is None:
                scored = s
        for p in self.packs:
            if not p.alive:
                p.respawn_ticks -= 1
                if p.respawn_ticks == 0:
                    p.alive = True
        return scored
```


# 起步策略

```python
"""起步策略：修改 MyStrategy.act；底部负责 JSON 收发。"""
import json
import math
import sys
from types import SimpleNamespace


class Action:
    def __init__(self):
        self.target_velocity_x = 0.0
        self.target_velocity_y = 0.0
        self.target_velocity_z = 0.0
        self.jump_speed = 0.0
        self.use_nitro = False


class MyStrategy:
    def act(self, me, rules, game, action):
        ball, arena = game.ball, rules.arena
        goal_z = arena.depth / 2 + arena.goal_depth / 2
        # 从对方球门指向球的方向，机器人要站到球的这一侧再往前冲
        gx, gz = ball.x, ball.z - goal_z
        n = math.hypot(gx, gz) or 1.0
        tx, tz = ball.x + gx / n * 2.5, ball.z + gz / n * 2.5
        if me.z < ball.z - 1:          # 已经在球后方：直接冲向球
            tx, tz = ball.x, ball.z
        dx, dz = tx - me.x, tz - me.z
        d = math.hypot(dx, dz) or 1.0
        speed = rules.ROBOT_MAX_GROUND_SPEED
        action.target_velocity_x = dx / d * speed
        action.target_velocity_z = dz / d * speed
        dist = math.dist((me.x, me.y, me.z), (ball.x, ball.y, ball.z))
        if dist < ball.radius + 1.5 * me.radius + 1 and ball.z > me.z:
            action.jump_speed = rules.ROBOT_MAX_JUMP_SPEED


def to_obj(v):
    if isinstance(v, dict):
        return SimpleNamespace(**{k: to_obj(x) for k, x in v.items()})
    if isinstance(v, list):
        return [to_obj(x) for x in v]
    return v


def main():
    strategy, rules = MyStrategy(), None
    for line in sys.stdin:
        msg = json.loads(line)
        if msg["type"] == "init":
            rules = to_obj(msg["rules"])
            print(json.dumps({"ready": True}), flush=True)
        elif msg["type"] == "turn":
            game = to_obj(msg["game"])
            actions = {}
            for robot in game.robots:
                if robot.is_teammate:
                    action = Action()
                    strategy.act(robot, rules, game, action)
                    actions[str(robot.id)] = vars(action)
            print(json.dumps({"tick": msg["tick"], "actions": actions}), flush=True)
        elif msg["type"] == "end":
            break


if __name__ == "__main__":
    main()
```
